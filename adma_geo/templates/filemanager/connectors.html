Globus
{% if globus_configured %}Checking…{% else %}Not set up yet{% endif %}
Copy data between storage systems, such as ADAPT and HCC Attic

Ask ADMA can browse your Globus collections and copy data between them, for example to back up ADAPT to HCC Attic. Globus checks every copied file, and nothing is ever deleted. You can also ask in the chat, for example "Copy the Test101 folder to my Attic backup folder with Globus".

{% if not globus_configured %}
To turn this on, ADMA needs a Globus app ID. It is free and takes about 5 minutes:
  1. Go to app.globus.org/settings/developers and choose Register a thick client or script that will be installed and run by users on their devices.
  2. Name it ADMA, register it, and copy its Client UUID.
  3. Add GLOBUS_CLIENT_ID= followed by that UUID to ADMA's .env file, and restart ADMA.
